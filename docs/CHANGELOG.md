# 更新记录

## 1.1.0

- 在原生头像旁添加「主人的工作台 / Personal space」标识，不替换头像和账户菜单；侧栏收起时自动隐藏标识。
- 移除标题栏下方原生的白色滚动渐变，与主区域共用连续壁纸；移除侧栏重复边框和随悬停变化的拖动高亮，保留原生侧栏拖动目标与键盘焦点提示。
- 外观与专注按钮相对内容区左侧、可见标题栏下方均保留 18px。
- 预加载首页和会话图片，切换时保留图像元素；图片完全使用 CSS 随容器铺放，不再由 JavaScript 延迟改变尺寸或缩放时降低透明度。
- ResizeObserver 与窗口 resize 合并测量；星尘画布等待尺寸稳定 180ms 后调整，保留粒子状态。图片不参与此延迟；空闲扫描不重置画布。
- 侧栏悬停预览展开期间隐藏外观按钮，离开后恢复，避免覆盖侧栏入口。
- 新增 `Update.cmd`，从解压目录运行即可关闭主题实例、修复安装并重新启动；保留 profile 和偏好设置。

验证覆盖按钮间距、原生白色渐变移除、侧栏预览状态样式及壁纸不再切换透明度。用户实测还原/缩小已正常，但最大化仍有残余抖动，当前未完全解决。开发视口模拟未可靠改变原生布局尺寸，不作为最大化修复通过的依据。

Windows / Chromium 的画面提交时序可能参与剩余问题，但尚未完成无主题对照或绘制轨迹分析，不能确认唯一根因。参考 [Electron 官方窗口缩放分析](https://www.electronjs.org/blog/tech-talk-window-resize-behavior)；该文所述旧缺陷已有修复，不直接等同于本客户端的问题。
